# Changelog

## 0.1.0 — 2026-10-20

Initial release of **Minimap Customizer**.

- Added category filters for native minimap icons, including Sailing facilities, tutors, shops, and skilling locations.
- Added optional direction arrow, sword, and looting bag markers.
- Added eight native-dot color pickers.
- Added separate visibility controls for foliage and rare trees.
- Set the default player marker to Direction arrow, with native NPC and ground-item dots.
